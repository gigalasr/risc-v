## How To Run
## Labor 7
- Labor 7 Aufgabe 1: `tools/vhdlmake/build/vhdlmake run alu_tb`
- Labor 7 Aufgabe 2: `tools/vhdlmake/build/vhdlmake run decoder_tb`
- Labor 7 Aufgabe 2/3: `tools/vhdlmake/build/vhdlmake run riub_only_risc_v_tb`

## Labor 6
- Labor 6: `tools/vhdlmake/build/vhdlmake run riu_only_risc_v_tb`
- Labor 6: `tools/vhdlmake/build/vhdlmake run decoder_tb`

## Labor 5
- Labor 5 Aufgabe 1: `tools/vhdlmake/build/vhdlmake run alu_tb`
- Labor 5 Aufgabe 2: `tools/vhdlmake/build/vhdlmake run decoder_tb`
- Labor 5 Aufgabe 3: `tools/vhdlmake/build/vhdlmake run register_file_tb`
- Labor 5 Aufgabe 4: `tools/vhdlmake/build/vhdlmake run ri_only_risc_v_tb`

## Labor 4
- Labor 4 Aufgabe 2: `tools/vhdlmake/build/vhdlmake run r_only_risc_v_tb`
- Labor 4 Aufgabe 3: `tools/vhdlmake/build/vhdlmake run r_only_risc_v_2_tb`

### Labor 3
- Labor 3 Aufgabe 2: `tools/vhdlmake/build/vhdlmake run sign_extension_tb`
- Labor 3 Aufgabe 1: `tools/vhdlmake/build/vhdlmake run decoder_tb`

### Labor 2
- Labor 2 Aufgabe 2: `tools/vhdlmake/build/vhdlmake run register_file_tb`
- Labor 2 Aufgabe 1: `tools/vhdlmake/build/vhdlmake run single_port_ram_tb`

### Labor 1
- Labor 1 Aufgabe 3: `tools/vhdlmake/build/vhdlmake run gen_mux_tb`
- Labor 1 Aufgabe 2: `tools/vhdlmake/build/vhdlmake run pipeline_register_tb`
- Labor 1 Aufgabe 1: `tools/vhdlmake/build/vhdlmake run alu_tb`

## Clone
Clone this repo using: ``git clone --recursive https://github.com/gigalasr/risc-v.git``

## Setup
Before you can run [vhdlmake](https://github.com/gigalasr/vhdlmake) you need to run ``source setup.sh``.
